Privacy · September 5, 2026

How Continuity Board handles data

Project names, notes, images, props, and panels are stored in IndexedDB on your device.

Normal board use sends no project data to us. There is no account or analytics tracker.

Local projects and the demo

Clearing site data removes saved projects from this device. Export a JSON backup before clearing it.

The sample demo uses memory only. Demo changes never read or write your saved projects.

Studio licenses

A Studio token and its last result are stored in localStorage. You can remove both by clearing site data.

License checks send only the token to Sociobot. The app checks at most once per day.

Sociobot and Dodo process checkout details. Payment card data never enters Continuity Board.

References and exports

Uploaded references remain in this browser. JSON and print/PDF exports are created on your device.

Exports include the source text you supply. You choose where exported files go.
